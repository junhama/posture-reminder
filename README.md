# 💺 Posture Reminder

良い姿勢を保つためのリマインダーPWAアプリです。定期的に通知を送って姿勢を意識させます。

## 機能

- **定期通知**: 15分 / 30分 / 1時間 / 2時間の間隔で姿勢チェックを通知
- **通知メッセージのカスタマイズ**: 好きなメッセージを設定可能（未設定時はヒントをランダム表示）
- **通知音**: 通知時にビープ音を再生（オン/オフ切替）
- **通知時間帯の制限**: 深夜の通知を防ぐため開始・終了時刻を設定可能
- **次の通知カウントダウン**: 次の通知までの残り時間をリアルタイム表示
- **今日の通知回数**: 1日の通知回数を記録・表示
- **テスト通知**: 設定を確認するためのテスト通知ボタン
- **設定の自動保存**: 設定は localStorage に保存され、次回起動時に復元
- **ダークモード対応**: OSの設定に合わせて自動切替
- **PWA対応**: オフライン動作、ホーム画面への追加が可能

## 使い方

1. 通知間隔・メッセージ・時間帯を設定
2. 「リマインダー開始」を押す
3. 通知を許可すると、設定した間隔で姿勢チェック通知が届きます
